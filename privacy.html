Privacy Policy

Hermes Calendar · last updated 12 November 2026

Scope

Hermes Calendar ("the application") is a private automation operated for a single individual on hardware that individual controls. The application has exactly one user: its owner. This policy describes what the application does with Google user data obtained through OAuth 2.0.

Data accessed

  • Google Calendar events on the owner's own calendar: titles, times, descriptions, and locations.
  • Google Account email address, used solely to identify the authorising account.

How data is used

  • Event data is used to render a daily agenda summary for the owner.
  • The application creates calendar events only when the owner explicitly requests and confirms each event.
  • Data is never used for advertising, profiling, analytics, or machine-learning model training.

Storage and location

  • Event data is processed in memory and is not persisted to a database.
  • OAuth credentials, including the refresh token, are stored on the owner's self-hosted server, readable only by the owner's user account.
  • Data is transmitted only to Google API endpoints over TLS. No third-party services receive any Google user data.

Sharing

Google user data is not sold, rented, shared, transferred, or disclosed to any third party, except where required by applicable law.

Retention and deletion

  • Event data is not retained after the agenda summary is produced.
  • Credentials persist until revoked by the owner or deleted from the server. To revoke: Google Account permissions. To delete locally, remove token.json from the host.
  • Revoking access immediately ends the application's ability to read or write calendar data.

Limited use

The application's use of Google API data adheres to the Google API Services User Data Policy, including its Limited Use requirements. Data obtained through Google APIs is used only to provide the functionality described above, which is visible and consented to by the owner.

Security

The application runs on hardware controlled by the owner, communicates outbound over TLS only, and opens no inbound network ports. Credentials are held in filesystem-restricted files on that machine.

Changes

Material changes to this policy will be reflected in the "last updated" date above.
