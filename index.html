Hermes Calendar

A private, single-user automation for a self-hosted assistant.

What this is

Hermes Calendar is a personal integration that lets a self-hosted AI assistant running on the owner's own hardware read and write the owner's Google Calendar. It is not a product, has no other users, and is not distributed.

What it does with Google data

  • Reads upcoming events to produce a daily agenda summary for the owner.
  • Creates calendar events only after the owner explicitly confirms each one.
  • Stores the OAuth refresh token locally on the owner's server; credentials are never transmitted anywhere except to Google's own API endpoints.
  • Does not share, sell, or resell any Google user data. No analytics, no telemetry.

Access and revocation

Access can be revoked at any time from the owner's Google Account permissions page.
